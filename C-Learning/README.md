# C-Learning — my personal C notes & practice code

By **Adarsh** — every file is my own hand-written study material.
C is where you finally see what the machine is really doing.

## How to use

1. Follow `00_ROADMAP.md` in order.
2. Compile & run each lesson:
   - Windows (MinGW): `gcc 01_first_program.c -o lesson.exe && lesson.exe`
   - Linux/macOS: `gcc 01_first_program.c -o lesson && ./lesson`
3. Every lesson is self-contained and heavily commented.
4. Finish with `PRACTICE_CHALLENGES.md`, then go read real C in the
   project folders next door (kilo is 1000 lines — a whole editor!).

## Files

- `00_ROADMAP.md` — my study order
- `01`–`30` — lessons: basics → pointers (the boss fight) → memory → files
- `CHEATSHEET.md` — syntax quick reference
