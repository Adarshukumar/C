# 25 C Challenges — by Adarsh

Rules: -Wall -Wextra clean, no warnings, free everything you malloc. — Adarsh

## Basics (01-06)
- [ ] 01. FizzBuzz + reverse a number's digits (12345 -> 54321).
- [ ] 02. is_prime below 100, then print twin primes.
- [ ] 03. my_strlen / my_strcpy / my_strcmp from scratch.
- [ ] 04. Count words, lines, chars of stdin (a mini `wc`).
- [ ] 05. Caesar cipher encrypt/decrypt from argv.
- [ ] 06. Binary <-> decimal converters both ways.

## Arrays & memory (07-12)
- [ ] 07. Reverse an array in place; rotate by k.
- [ ] 08. Dynamic int vector with push/pop/insert (lesson 21++).
- [ ] 09. Matrix multiply with heap-allocated 2D (int**).
- [ ] 10. Find duplicates with a hash table you build yourself.
- [ ] 11. Bubble + selection + insertion sorts, compare swap counts.
- [ ] 12. Binary search recursive AND iterative.

## Strings & structs (13-17)
- [ ] 13. Split a sentence into words (array of char*).
- [ ] 14. Student struct array: sort by name with qsort + function pointer.
- [ ] 15. Stack (push/pop/peek) with linked nodes.
- [ ] 16. Queue (enqueue/dequeue) — singly linked.
- [ ] 17. Singly linked list: reverse in place (3-pointer walk).

## Real programs (18-22)
- [ ] 18. Todo storage: load/save structs to a binary file.
- [ ] 19. CSV parser: parse + print column averages.
- [ ] 20. Mini grep: search a file for a word, print line numbers.
- [ ] 21. Snake game in the terminal (ncurses or ANSI escapes).
- [ ] 22. Tiny malloc-free arena allocator (bump allocator).

## Boss fights (23-25)
- [ ] 23. Read kilo (in the collection!) and explain every function.
- [ ] 24. Dynamic string type with append, concat, free.
- [ ] 25. Generic swap via memcpy + size (then: why does C have no swap()?).
